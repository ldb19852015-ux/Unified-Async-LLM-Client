# Unified Async LLM Client (Python 3.12)

Cliente unificado, asíncrono y desacoplado para interactuar con modelos de lenguaje de **OpenAI**, **Anthropic** y **Google Gemini** mediante sus SDKs oficiales no bloqueantes, validación previa con **Pydantic v2** y manejo controlado de excepciones.

## 🚀 Requisitos Previos

- Python 3.12+
- API Keys de al menos uno de los proveedores (OpenAI, Anthropic o Google Gemini).
